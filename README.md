# My Mods
The list of all my mods available here, categorised by game.

# DiRT 2
[Any car on any track](https://github.com/HungryManticore/DiRT-2-ACAT) - removes restrictions found in Free Race mode, you can now race any car on any track

# DiRT Showdown
[Single Race mode](https://github.com/HungryManticore/Dirt-Showdown-Single-Race) - transforms Split Screen into Single Race

# Need for Speed Hot Pursuit 2
[Hide HID Devices](https://github.com/HungryManticore/HideHIDDevices) - Hot Pursuit 2 crashes to desktop when it detects an incompatible HID device. This script allows user to hide such devices from the game, thus preventing the crash.

# Need for Speed Hot Pursuit Remastered
[Event Randomizer](https://github.com/HungryManticore/NFSHPR-EventRandomizer) - randomises opponents and cops (which always pick cars from the same class as the player's car), weather and time of day, bringing some replay value to the game

# Need for Speed Most Wanted 2012
[Open Races](https://github.com/HungryManticore/MW2012-Open-Races) - allows the player to use any car in any race, randomises opponents

# Test Drive Unlimited
[Car ownership status displayed at the dealer](https://github.com/HungryManticore/TDU_DealerOwnedGreen) - when visiting a dealer, cars already owned by the player are displayed in green font

[Traffic physics patch for high refresh rates](https://github.com/HungryManticore/TDU-TrafficFPSFix) - fixes the broken traffic physics when the game is ran above 60 fps

[Save states in the game's root directory](https://github.com/HungryManticore/TDU-Savepath) - allows placing saves in the game's root directory

[Open Races](https://github.com/HungryManticore/TDU-Open-Races) - allows bringing any car to any race and adjusts the opponents' class, after the event has already been won

# Contributions to other projects

[Forza Horizon 1 Reimagined](https://github.com/FH1-ReImagined/ForzaHorizon1-ReImagined) - custom single player races, available after the player's won a Festival Race or a Street Race

[Speedbreaker](https://github.com/SpeedBreakerProject/speedbreaker) - option to enable cops in Custom Race

[Open Test Drive Unlimited](https://github.com/opentestdriveunlimited/OpenTestDriveUnlimited)
- custom single player races; after obtaining a gold medal in an event, Custom Race mode allows players to change a Race into a Time Trial and vice versa, set the number of opponents, laps, AI drivers, toggle traffic and cops on and off
- mark vehicles already owned with green font when visiting a dealer
